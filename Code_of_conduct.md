# Code of Conduct

This is a small, early-stage project. The short version: be respectful,
assume good faith, and keep disagreements about the code, not the person.

- Harassment, insults, or discriminatory language won't be tolerated in
  issues, discussions, or pull requests.
- Disagreements about design or implementation are welcome and expected
  — argue the technical point, not the person making it.
- If someone violates this, open an issue tagged `conduct` or contact
  the maintainer directly. Reports will be handled privately.

This will get more formal if and when the project has more than one
maintainer. For now, this is the whole policy.
